# Roadmap

## Vision

PolicyLens aims to become the standard tool for website-policy consistency verification, helping companies maintain transparent and accurate legal documentation.

## Planned Features

### Q3 2026 — Foundation

- ✅ **Landing page** — Premium hero, features, workflow
- ✅ **Website crawling** — Firecrawl integration
- ✅ **AI analysis** — DeepSeek-powered fact extraction + comparison
- ✅ **Consistency report** — Score, findings, exports
- ✅ **Documentation** — README, API docs, deployment guide

### Q4 2026 — Growth

- [ ] **User authentication** — Clerk/Auth.js integration with Google and GitHub OAuth
- [ ] **Saved reports** — Persistent report history per user
- [ ] **Multi-page crawl** — Parse sitemap.xml for comprehensive site coverage
- [ ] **PDF export** — Professional PDF reports via @react-pdf/renderer
- [ ] **Rate limiting** — API rate limiting for public deployment
- [ ] **Light mode** — Theme toggle support

### Q1 2027 — Scale

- [ ] **Scheduled monitoring** — Weekly/monthly auto-scans with email alerts
- [ ] **Historical comparisons** — Before/after diff view for tracked sites
- [ ] **Team workspaces** — Share reports across teams
- [ ] **Browser extension** — One-click analysis from any website
- [ ] **API access** — Public API for programmatic analysis
- [ ] **Webhook notifications** — Slack, Discord, email integration

### Q2 2027 — Enterprise

- [ ] **Multi-language support** — Analyze policies in multiple languages
- [ ] **Jurisdiction detection** — Auto-detect applicable regulations (GDPR, CCPA, LGPD)
- [ ] **Custom checklists** — Industry-specific compliance checklists
- [ ] **Slack/Discord bot** — Analyze URLs directly from chat
- [ ] **GitHub integration** — Auto-analyze on PR to docs/ folder
- [ ] **White-label reports** — Custom branded reports for agencies

## Non-Goals

The following are explicitly out of scope:

- **Legal document generation** — We analyze existing policies, we don't write them
- **Legal advice** — PolicyLens is an analysis tool, not a law firm
- **Regulatory filing** — We don't submit documents to regulatory bodies
- **Contract management** — Our focus is website-policy consistency, not general contract lifecycle
