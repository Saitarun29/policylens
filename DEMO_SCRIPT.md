## Recording Tips

1. **Pre-set API keys** in `.env.local` before recording
2. Use a **well-known website** (vercel.com works well — finds docs)
3. Record at **2x resolution** and downscale for crisp text
4. Use **Chrome DevTools** → Console → Sensors → CPU throttling if the analysis completes too fast
5. Add **gentle zoom-in** (105%) during the findings section for visual variety
6. **Cursor should be visible** — use cursor highlights in editing

## Music Suggestions

- Lo-fi hip hop (chill, instrumental)
- Minimal electronic (ambient)
- Avoid vocals — they compete with narration/captions
